# Stakeholder Map — Academic Success Portfolio

## Stakeholders

| Stakeholder | Interest | Decision-maker vs. Influencer | Source |
|---|---|---|---|
| The user (sole developer/author) | Wants the project to genuinely teach the four target skill areas (Pandas, Data Cleaning, Intro/Intermediate ML, Feature Engineering) and to hold up as a portfolio piece | Decision-maker (sole) | [Q5] |
| End readers of the portfolio (Kaggle Learn graduates) | Want a worked example that maps directly to skills they just learned | Influencer (their needs shaped the intent, but they do not decide scope) | [Q2] |

## Decision-Makers vs. Influencers

Scope and priority decisions rest solely with the user — this is a solo project with no other decision-makers or approvers. [Q6]

## Communication Requirements

None — solo project, no reporting cadence needed. [Q7]

## Assumptions & Open Questions

None.
